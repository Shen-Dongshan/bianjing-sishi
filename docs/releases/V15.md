## 本次更新

- 六首背景音乐始终复用同一个音频元素；下一首只预载压缩文件，换曲直接切换来源，避免部分手机浏览器对新播放器再次限制播放。
- 点击展卷时同步恢复音频上下文并请求播放，恢复完成前不再暂停配乐；中断的播放请求可以重试，触摸结束与点击均可用于恢复受限配乐。
- 返回前台或恢复页面时继续处理声音状态；配乐单独受限时显示点击恢复配乐，点击即可重试。关闭声音后不会被后续触摸重新开启。
- 保留音乐与环境音的独立控制、六首原录音随机直接切换、单页单轨和多页声音互斥；未修改画卷、对白、天气或环境音素材。
- 增加移动端播放权限、自动换曲、中断恢复与前后台状态的回归检查；已在手机尺寸浏览器验证配乐实际输出，尚未连接iOS或安卓实体手机。

## 素材和实现边界

- 手机配乐问题按旧版代码中的逐元素播放许可及异步恢复中断隐患修复；实体手机上的具体触发条件未作远程复现。
- Chromium桌面及390×844手机尺寸浏览器实测配乐非零输出、独立音乐开关、直接换曲、关闭环境音仍有配乐，且仅有一个HTMLAudioElement；未连接iOS、安卓或微信内置浏览器真机。
- 权限回归模拟单个媒体元素分别授权，验证18次自动换曲、异步上下文恢复、中断重试、静音及后台状态；IAB切换标签未确认document.hidden，未将其记作真机后台恢复验证。
- 六首原MP3、四季底图及瓦片、环境音和对白素材保持原字节；只为新增版本文字补齐内置宋体六个汉字，保留原字体轮廓和SIL OFL许可。
- Github Release附件已逐项核对大小与SHA-256；Pages成功后核对18个公网资源摘要，以及六首配乐的HEAD与206分段响应。
- 背景音乐和环境音继续独立控制；关闭声音后触摸画面不会重开。网站仍以点击展卷作为启音手势，遵守手机浏览器的播放限制。
- 原画、AI艺术演绎、配乐及中文叫卖等既有版权说明均保持。开放世界继续显示开发中且禁用。
